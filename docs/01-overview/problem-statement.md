# Problem Statement

Navigating the complex, branching continuity of the Spider-Verse across comics, animated films, and live-action media is difficult for fans. There is no unified, visual database to explore these connections.

Traditional wikis present information in dense text formats with hyperlinks, which fails to convey the *chronological and dimensional relationships* between characters (e.g., how Miles Morales crossing over to Earth-616 affects the timeline).

The Amazing Web solves this by spatializing the data: turning timelines into physical branches in a 3D space.
