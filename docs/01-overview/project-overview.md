# Project Overview

## What is The Amazing Web?
The Amazing Web is an interactive 3D timeline and directory mapping the entire Spider-Verse. It tracks the various continuities, alternate Earths, crossover events, characters, and live-action movies across the Marvel Multiverse.

## Core Features
- **3D Multiverse Graph**: A WebGL-powered 3D timeline rendering thousands of nodes (characters, events) across branching Earth timelines.
- **Content Directory**: A searchable, filterable directory of every Spider-variant.
- **Admin Controls**: Secure, authenticated content management tools built directly into the UI.
- **Dynamic Image Hosting**: Direct integration with Supabase Storage for character profile pictures and event images.

## Target Audience
- Marvel fans and researchers looking to understand the complex web of Spider-Man continuities.
- Developers interested in WebGL, React-Three-Fiber, and full-stack TypeScript applications.
