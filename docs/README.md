# The Amazing Web Docs

Welcome to the official documentation for The Amazing Web, a highly interactive 3D timeline and directory mapping the entire Spider-Verse.

This project bridges the gap between various Spider-Man continuities, including live-action films, animated series, and comic book runs, presenting them in a unified, visually striking 3D multiverse graph. 

## Repository Structure
- **Frontend/**: A Vite + React application powered by TanStack Router and Three.js.
- **src/**: An Express.js backend providing RESTful API endpoints.
- **prisma/**: Database schema and migrations for PostgreSQL.
- **scripts/**: Utility scripts for data seeding, scraping, and maintenance.

For detailed information, please explore the specific sections within the `docs/` directory.
