# User Guide

## Exploring the 3D Timeline
- **Navigation**: Click and drag to rotate the 3D space. Scroll the mouse wheel to zoom in and out.
- **Nodes**: Hover over any glowing node to see details about the character or event. Click a node to open its full profile.
- **Branches**: Each colored line represents a different Earth/Universe. 

## Using the Directory
- Click the **Directory** button in the top navigation.
- Use the filter chips at the top to filter characters by **Earth**, **Medium** (Comics, Animated, Live-Action), or **Tags**.
- Use the search bar to find characters by name or alias.

## Admin Controls
If you have the Admin API key configured in your `localStorage`:
- Edit buttons will appear on all character and event cards.
- A floating "Add Character" button will be visible in the Directory.
- You can upload images directly from your computer; they will be hosted on Supabase automatically.
